## How It Works

1. **Name -> SHA-256 Lookup:** `ghostFFIByName(name, { symbols })` resolves the exact OS/arch native binary (`.dll`, `.so`, `.dylib`) or `wasm32-wasi` fallback from [`awesome-os/b8g-ghost/manifests/index.json`](https://raw.githubusercontent.com/awesome-os/b8g-ghost/main/manifests/index.json).
2. **O(1) Immutable Fetch:** Downloads directly from `https://github.com/awesome-os/b8g-ghost/releases/download/cas-v1/<sha256>` into a deduplicated machine CAS (`%LOCALAPPDATA%/AwesomeOS/cas` or `~/.local/share/awesome-os/cas`).
3. **Zero-Trust Verification:** Verifies the exact SHA-256 digest before atomically committing to CAS — warm hits take **0 network calls** and support side-by-side versions with zero DLL Hell.
